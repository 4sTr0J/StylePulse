# 🤖 AI-Agent

An AI-powered assistant built using the **Google Gemini API**. This project is designed to provide intelligent responses, automate tasks, and serve as a foundation for building advanced AI applications.

## 🚀 Features

- 💬 AI-powered conversational assistant
- 🧠 Google Gemini API integration
- ⚡ Fast and responsive interactions
- 🔒 Secure API key management using environment variables
- 📂 Clean and modular project structure
- 🛠 Easy to customize and extend

## 🛠 Technologies Used

- Python 3.x
- Google Gemini API
- Git & GitHub

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Aravinda123-arch/AI-Agent.git
```

2. Navigate to the project

```bash
cd AI-Agent
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Create a `.env` file and add your Gemini API Key

```env
GEMINI_API_KEY=your_api_key_here
```

5. Run the project

```bash
python main.py
```
